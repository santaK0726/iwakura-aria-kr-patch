# v0.5.1 — 2026-11-05

기존 v0.5.1 게임 데이터를 변경하지 않고 스위치용·에뮬레이터용 공개 차분 패키지로 정리했습니다.

- 원본이 필요한 플랫폼별 패키지와 공통 생성기를 제공합니다.
- 원본 7개 MPK의 버전·크기·SHA-256을 확인하고 새 폴더에만 출력합니다.
- 복원한 결과는 기존 개인용 스위치/에뮬레이터 패키지와 같은 파일별 해시를 사용합니다.
- 원본이 다르거나 출력 폴더가 이미 있으면 중단합니다.
- 기존 개인용 전체 리소스 ZIP은 공개 업로드 대상에 포함하지 않았습니다.

개발판 배포입니다. 대본 138개 원문 유지 항목과 기타 범위·검수 한계는 README 및 verification/release.json에 명시했습니다. 스위치 실기, v0.5.1 추가 대사와 전 루트 실행은 NOT RUN입니다. 기존 v0.5 UI의 사용자 수락 기록만 해당 UI 범위에 유지합니다.
